# Rilis v1.1.0 — Kolaborasi Anggota & Hapus Daftar Atomik

Tanggal: 2026-09-16
Status: Released

## Ringkasan

Rilis lanjutan setelah v1.0.0: melengkapi F2 (hapus daftar atomik), menambahkan
F4 (kolaborasi & keanggotaan), pengujian otomasi untuk manajemen tugas,
serta perbaikan UI autentikasi dan homepage.

## Fitur Baru

- **Hapus daftar atomik (F2):** `DELETE /lists/{list}` menghapus daftar beserta
  tugas & anggota dalam satu transaksi (`DB::transaction`); hanya owner via
  `ListPolicy::delete`.
- **Kolaborasi & keanggotaan (F4):**
  - Relasi model `TodoList::members()` dan `User::joinedLists()` (pivot `list_user`).
  - `POST /lists/{list}/members` — owner menambah anggota.
  - `DELETE /lists/{list}/members/{member}` — owner menghapus anggota.
  - `GET /lists/joined` — daftar yang diikuti user.
  - Otorisasi `manageMembers` (hanya owner).
- **Manajemen tugas (F3):** feature test CRUD, validasi, dan otorisasi tugas.
- **UI Autentikasi (F1):** login/register/profil memakai layout bersama,
  homepage redesain, font Figtree.
- Pengaktifan otorisasi kontroler (`Controller::authorize`).

## Perbaikan

- Test smoke & E2E disesuaikan dengan teks dan heading homepage yang baru.

## Catatan Teknis

- Framework: Laravel v13.32.0 · PHP 8.5.
- Database: MySQL (dev `jara-todolist`; test `jara`) via `pdo_mysql`.
- Frontend: Blade + Tailwind/PostCSS + Vite (build terverifikasi, font Figtree).
- Test: unit + feature (`php artisan test`, 51 lulus) dan E2E Playwright
  (`npm run test:e2e`, 2 lulus).
- Route baru: `DELETE /lists/{list}`, `GET /lists/joined`,
  `POST /lists/{list}/members`, `DELETE /lists/{list}/members/{member}`.
