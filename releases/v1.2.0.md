# Rilis v1.2.0 — Admin Kelola Akun, UI Blade & Named Routes

Tanggal: 2026-09-16
Status: Released

## Ringkasan

Rilis setelah v1.1.0 berfokus pada perapihan perutean (named routes), penyajian
antarmuka web berbasis Blade untuk halaman daftar/anggota/admin, serta
manajemen akun pengguna di area admin (F5 parsial) lengkap dengan feature test.

## Fitur Baru

- **Admin & akun pengguna (F5 parsial):** `AdminController` —
  - `GET /admin` dan `GET /admin/users` — dashboard daftar akun (paginate).
  - `POST /admin/users` — admin menambah akun (nama, email, password, role).
  - `DELETE /admin/users/{user}` — admin menghapus akun; admin tidak dapat
    menghapus akun sendiri (403).
  - Dikhususkan untuk role `admin` via middleware admin + policy.
- **UI Blade:** halaman `lists/index`, `lists/joined`, `lists/show`,
  `lists/members`, dan `admin/index`; menu area admin pada layout.
- **Named routes:** seluruh route web diberi nama (`lists.*`,
  `lists.members.*`, `tasks.*`, `admin.*`, dsb.); parameter `/lists/{list}`
  dibatasi `whereNumber`; `GET /lists/joined` diprioritaskan di atas
  `/lists/{list}`.
- **Relasi & otorisasi:** `TodoList::tasks`, `Task::list`; `ListPolicy::view`
  kini mengizinkan member untuk melihat daftar.
- **Feature test:** `AdminUserTest` (menambah & menghapus akun oleh admin).

## Perbaikan

- Respon JSON/Blade konsisten di `ListController` & `ListMemberController`
  (dual response via `expectsJson`).
- Update profil kini dilayani `PUT/PATCH /profile`; pengguna ber-autentikasi
  yang membuka halaman utama dialihkan ke `/lists`.
- `phpunit.xml` berpindah ke SQLite `:memory:` dan `TaskTest` memakai
  `RefreshDatabase` agar lebih cepat dan terisolasi.

## Catatan Teknis

- Test: unit + feature (`php artisan test`, 56 lulus / 130 assertion).
- Route baru: `GET /admin`, `GET /admin/users`, `POST /admin/users`,
  `DELETE /admin/users/{user}`.
