# Release — JARA (Advanced Todo List)

Folder ini berisi catatan perilisan (release notes) per versi.

Alur:
1. Selesaikan milestone (lihat `PRD.md` §9).
2. Buat file `vX.Y.Z.md` mengikuti template di bawah.
3. Perbarui `Changelog.md`.
4. Beri `git tag vX.Y.Z`.

---
