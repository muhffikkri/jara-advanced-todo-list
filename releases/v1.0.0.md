# Rilis v1.0.0 — Autentikasi, Manajemen List & Tugas

Tanggal: 2026-09-16
Status: Released

## Ringkasan

Rilis resmi pertama yang memadukan fondasi F0, autentikasi & akun (F1),
manajemen list (F2 — CRUD tanpa delete), manajemen tugas (F3),
serta pengujian terotomasi (unit, feature, E2E Playwright).

## Fitur Baru

- **Autentikasi (F1):** register, login, logout, profil (edit/update), role
  `user`/`admin`, middleware admin, seeder akun admin & user contoh (Blade + Session).
- **List (F2):** buat daftar (otomatis menjadi pemilik), lihat daftar milik &
  diikuti, update nama/deskripsi khusus owner; otorisasi `ListPolicy` → 403 untuk
  aksi non-owner; validasi via `StoreListRequest`/`UpdateListRequest`.
- **Tugas (F3):** buat, edit, hapus, toggle selesai, prioritas
  (`low`/`medium`/`high`/`urgent`), tenggat waktu; otorisasi `TaskPolicy` untuk
  owner/member list; validasi via `StoreTaskRequest`/`UpdateTaskRequest`.
- **Skema database:** tabel `lists`, `tasks`, `list_user`, kolom `role` pada users.
- **Pengujian:** unit test, feature test (auth, skema, policy, form request,
  CRUD list, smoke), dan E2E Playwright (`npm run test:e2e`).

## Perbaikan

- `TodoList` menambahkan `owner_id` ke `fillable` sehingga pembuatan daftar
  menyimpan pemilik dan daftar muncul pada index milik user.

## Catatan Teknis

- Framework: Laravel v13.32.0 · PHP 8.5 · SQLite (dev).
- Frontend: Blade + Tailwind/PostCSS + Vite (build terverifikasi).
- Autentikasi web: AuthController + session, middleware `admin` untuk role admin.
- Test: `php artisan test` (36 lulus) dan `npm run test:e2e` (2 lulus).

## File/Artefak

- Source: tag `v1.0.0` pada branch `main`.
- Endpoint utama: `/register`, `/login`, `/lists`, `/lists/{list}`,
  `/lists/{list}/tasks`, `/tasks/{task}`, `/profile`, `/admin`.

## Catatan Milestone Berikutnya

- F2: hapus daftar atomik (tugas + keanggotaan ikut terhapus, `DB::transaction`).
- F4: kolaborasi & keanggotaan.
- F5: admin tambah/hapus akun, tampilan progres per daftar.
- Feature test CRUD tugas.
